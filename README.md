A tiny Python program (`main.py`) that writes one funny one-line resignation letter to `/output/entry.txt`: a fortune teller resigns with proper two weeks' notice — she saw this coming, and honestly, her boss should have too. The line is 128 characters, fits the 1–140 character gate, and was chosen from 16 candidates scored against the published judge criteria.
